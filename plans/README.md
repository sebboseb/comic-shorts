## Findings not planned (recorded so they aren't re-audited)

- **ESRGAN upscale is untiled** (`pipeline/stage3_cleanup.py:62-79`):
  full-frame 4x on ~1600px panels may OOM on the 24GB GPU / MPS, and
  panels just under the 2200px target get 4x'd then downscaled (wasted
  compute). MED confidence — stage 3 has never been run on this comic.
  Verdict: investigate on the GPU box on first real run before writing a
  fix plan; the standard remedy is tile-based inference (Real-ESRGAN
  convention, ~128–512px tiles with overlap).
- **tag_ui server accepts cross-origin writes** (`tools/tag_ui.py:227-249`):
  binds 127.0.0.1 (good), but POST handlers do no Origin/Host check, so a
  malicious web page open in the same browser could rewrite
  `config/comic.yaml`, panel overrides, or crops while the tool runs.
  Blast radius is local project files, tool only runs during tagging
  sessions. Worth a ~20-line fix (reject POSTs whose `Origin` header
  isn't `http://127.0.0.1:8765`) whenever tag_ui is next touched; not
  planned as it didn't make the top-5 cut.
- **requirements.txt is unpinned** (all 8 deps): fine for a solo project
  today; pin (`pip freeze > requirements.lock`) when the GPU box needs to
  reproduce this env. Not planned — one command, no design.
- **`_parse_json` duplicated** (`pipeline/stage2_understand.py:66`,
  `pipeline/stage4_story.py:67`): deliberate two-copy duplication, both
  covered by tests from plan 001. Deduplicate opportunistically when a
  third consumer appears (plan 004's maintenance note suggests
  `pipeline/io.py` as the eventual home). Rejected as a standalone plan —
  churn exceeds benefit.
- **`config/characters/test.png` is a stray crop** not referenced by
  comic.yaml. Delete by hand; not plan-worthy.
- **28% unknown-speaker rate** (81 of ~284 dialogue lines in
  `work/understanding.json`): this is the review-gate workload the README
  already documents, not a bug. Plan 005's shared-reference-image change
  may reduce it on future runs.
- **review.py partial HTML escaping**: folded into plan 004, not separate.
